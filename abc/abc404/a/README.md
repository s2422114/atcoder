# ABC404 A - Not Found

- URL: https://atcoder.jp/contests/abc404/tasks/abc404_a
- 結果: AC（方針を相談して自力）
- 解法: 2段階。
        (1) S を全部見て used[S[i]-'a'] = true で出現に印をつける
        (2) 0〜25 を順に見て、印がない最初の位置を (char)('a'+i) で出力
- 学び:
  - 文字 → 数字: S[i] - 'a'（'a'=0 … 'z'=25）
  - 数字 → 文字: (char)('a' + i)。char にキャストしないと数値が出る
  - バケット配列の文字版（値＝文字を添字にして記録）
  - 【詰まった点】ループ回数が段階で違う。
    印をつけるのは S.size() 回、探すのは 26 回。混同すると答えが出ない
  - 見つけたら break（複数あってもどれでもよい）
