# ABC406 A - Not Acceptable

- URL: https://atcoder.jp/contests/abc406/tasks/abc406_a
- 結果: AC（自力）
- 解法: 時を比較、同じなら分を比較。A>C または (A==C && B>D) なら Yes
- 学び:
  - 制約「(A,B)≠(C,D)」が同時刻ケースを排除 → 場合分けが1つ減る
  - 別解: 時刻を1つの数にまとめて比較（場合分け不要）
      if (A*100 + B > C*100 + D) → Yes
    分は0〜59で2桁に収まるので *100 で桁が混ざらない
    （ABC432の「位の重みを掛ける」と同じ考え方。時刻比較の定石）
