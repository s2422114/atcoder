# ABC408 A - Timeout

- URL: https://atcoder.jp/contests/abc408/tasks/abc408_a
- 結果: AC（自力）
- 解法: 1-indexed の T(N+1) を使い、T[0]=0（現在＝最後に叩いた時刻）を番兵に。
        各 i で T[i]-T[i-1] が S を超えたら寝る → No
- 学び:
  - 【気づき】i=1 から進めるとき、T[0]=0 が自動で「初期状態の番兵」になる
    1-indexed だと最初の間隔も特別扱いなしで計算できる（境界を余白で吸収）
  - 「S+0.5秒以上で寝る」= 整数の間隔なら「S より大きい」と同義
    → if (T[i]-T[i-1] > S) と整数だけで書ける（小数比較は誤差の温床なので避ける）
  - 問題文の +0.5 は「ちょうどS秒はセーフ」を明確にするための表現
