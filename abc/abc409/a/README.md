# ABC409 A - Conflict

- URL: https://atcoder.jp/contests/abc409/tasks/abc409_a
- 結果: AC（条件の読み違いで1度WA→修正）
- 解法: 各iについて T[i]=='o' && A[i]=='o'（両方が欲しがる）が1つでもあれば Yes
- 詰まった点と学び:
  - 【罠】T[i]==A[i]（同じ文字か）はダメ。両方 'x'（2人とも欲しくない）も
    一致してしまう → 明示的に両方 'o' を判定する
  - 「2人とも欲しがっている」を「一致している」と読み替えるとズレる
    （ABC421と同じ、条件の読み替えミス）
  - 見つけたら break で早期打ち切り
