# ABC452 B

- URL: https://atcoder.jp/contests/abc452/tasks/abc452_b
- 結果: AC
- 解法: 各マスの隣接数を4方向チェックで数え、3個以下なら '#'、そうでなければ '.'
        （問題文の「端にある＝隣接3個以下」の定義をそのまま実装）
- 学び:
  - 隣の存在チェックは「隣の座標が盤面内か」で見る: j-1>=1, j+1<=W, i-1>=1, i+1<=H
    j-(j-1) のような式は常に1になり判定にならない
  - sum はマスごとに 0 に戻す（ループの中で宣言）
  - vector<vector<string>> の初期値は "." （'.' は char なので不可）
  - 配列サイズは H+1, W+1（1-indexed で回すため）
  - 別解: 端の条件を直接 i==1||i==H||j==1||j==W で判定してもよい
  - ABC458 B の4方向チェックがそのまま応用できた
