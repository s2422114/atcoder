# ABC453 B - センサーの記録

- URL: https://atcoder.jp/contests/abc453/tasks/abc453_b
- 結果: AC（構造を相談して修正）
- 解法: シミュレーション。「最後に保存した値」を int 変数 last で持つ。
        時刻0は無条件で保存・出力し last=A[0]。
        時刻1〜T は abs(A[i]-last) >= X なら出力して last=A[i]。
        保存しないときは何もしない（last がそのまま残る）
- 詰まった点と学び:
  - 【核心】比較相手は「1つ前の値」ではなく「最後に保存した値」
    入力例の時刻5は、直前の時刻4(30)ではなく時刻3(21)と比べる
  - 必要なのは最新の1つだけ → 配列に履歴を貯める必要はない。int 変数1つで足りる
    配列にすると添字管理が複雑になって崩れる
  - 「保存しないときは更新しない」＝何もしないことで前の値が残る
  - 入力は A_0 〜 A_T の T+1 個。ループは i=0 から
