# ABC454 B

- URL: https://atcoder.jp/contests/abc454/tasks/abc454_b
- 結果: AC（自力）
- 解法: バケット配列 cnt[服番号] に着用者数を集計し、1本の配列で2問に答える
        質問1（全員違う服か）: cnt[i] >= 2 の服がなければ Yes
        質問2（全種類着られているか）: cnt[i] == 0 の服がなければ Yes
- 学び:
  - 「値そのものを添字にして数える」バケット配列。1つの集計で複数の判定ができる
  - 全要素が異なるかの判定方法3つ:
    (1) set に入れて size == N か（重複が自動で消える）
    (2) バケットで cnt >= 2 がないか（今回）
    (3) ソートして隣同士が同じか
  - バケットは値の範囲が小さいとき有効（今回 F_i <= M <= 100）
    範囲が大きいときは map/set を使う
