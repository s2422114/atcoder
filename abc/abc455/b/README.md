# ABC455 B - 点対称な長方形領域

- URL: https://atcoder.jp/contests/abc455/tasks/abc455_b
- 結果: AC（問題理解から解説を受けて実装、3つのバグを修正）
- 解法: 四重ループで長方形(h1,h2,w1,w2)を全探索。各長方形について
        内側の二重ループで全マスを見て、S[i][j] == S[h1+h2-i][w1+w2-j]
        が全て成り立てば点対称 → カウント
- 理解のポイント:
  - 点対称 = 180度回転しても同じ = 行も列も両方ひっくり返して一致
    （行だけ反転＝上下鏡、列だけ反転＝左右鏡、両方＝180度回転）
  - マス(i,j)の対称の相手は (h1+h2-i, w1+w2-j)
    h1+h2 が上下の和 → 上端と下端が入れ替わり、真ん中は自分自身
  - 1×1 の長方形は必ず点対称（自分が自分の相手）
- 詰まった点と学び:
  - 【TLE】for(h1=1; h1<=H;) と h1++ を書き忘れ → 無限ループ
    ループが6段あると単純ミスが紛れる。TLEはまず無限ループを疑う
  - bool ok は true から始める（点対称と仮定→反例で false に崩す）
  - vector<string> は S[i] が「i行目の文字列」、S[i][j] はその j 文字目。
    i は自分で1-indexed、j は文字列標準の0-indexed で混在する
    → 入力時に S[i] = " " + S[i] でダミーを足して両方1-indexedに揃える
- 難易度: 問題理解・数式への翻訳・六重ループの実装量が同時に来る重い問題
