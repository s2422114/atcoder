# ABC456 B - 456

- URL: https://atcoder.jp/contests/abc456/tasks/abc456_b
- 結果: AC（方針を相談、未初期化バグを修正）
- 解法: 各サイコロで4,5,6が何面あるか数える。3個に4,5,6を割り当てる
        6通り(3!)のパターンごとに面数を掛け合わせ、全部足す。÷216 が確率
- 学び【場合の数の基本】:
  - 掛け算 = 「AもBも」独立な選択の組み合わせ数
    （サイコロ1が2通り × 2が3通り × 3が1通り = 6通り）
  - 足し算 = 「AかBか」同時に起きないパターンの合算（6パターンを += で足す）
  - 全体の出方 216 = 6×6×6 も同じ理由で掛け算
- 詰まった点:
  - 【罠】int cnt4_1, cnt4_2, ...; は初期化されずゴミが入る。必ず = 0 を各変数に
    実行のたびに結果が変わる = 未初期化のサイン
  - 変数を二重宣言するとコンパイルエラー → main が更新されず古い実行結果が出る
    「直したのに変わらない」ときはコンパイル成功を確認する
- 改善案: cnt[サイコロ][数字] の二次元配列にすれば cnt[i][a]++ の1行で数えられる
        （バケット配列。9個のif が消える）
