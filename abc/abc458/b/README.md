# ABC458 B - Count Adjacent Cells

- URL: https://atcoder.jp/contests/abc458/tasks/abc458_b
- 結果: AC（方針転換して自力）
- 解法: 各マス(i,j)について上下左右の4方向を独立にチェックし、
        グリッド内(1<=行<=H, 1<=列<=W)なら cnt++。合計を出力
- 学び:
  - 【方針の選び方】「角なら2、辺なら3」とマスを分類すると場合分けが爆発する
    （角4種・辺4種・H=1やW=1の特殊ケース）
    → 4方向を1つずつ「あるか?」と聞く方がシンプル。合計すれば自動的に正解
  - 特殊ケース(H=1等)も、方向チェックなら条件がfalseになるだけで自動対応
  - 全体を分類せず個別に判定する（ABC429と同じ発想）
  - 出力形式: 行内は空白区切り、行末で改行。j<W のときだけ空白を出す
  - 難易度の種類: これは「難しい」ではなく「面倒」。方針が見えれば手を動かすだけ
