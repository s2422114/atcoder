# ABC459 B

- URL: https://atcoder.jp/contests/abc459/tasks/abc459_b
- 結果: AC（if の羅列でゴリ押し）
- 解法: 各文字列の先頭文字を if の連続で判定し、対応する数字を出力
- 詰まった点と学び:
  - 【罠】S[0]=='a' || 'b' || 'c' はダメ。'b' 単独は常にtrueになり、
    条件が必ず成立してしまう → S[0]=='a' || S[0]=='b' || ... と毎回 == を書く
  - 短く書く手:
    (1) 範囲比較: 'a'<=c && c<='c'（文字は文字コード順なので大小比較できる）
    (2) 対応表を文字列で: string t="22233344455566677778889999";
        cout << t[S[0]-'a'];  ← S[0]-'a' で 0〜25 の添字に変換（ABC422の応用）
  - 本番はゴリ押しでも確実に通す方が価値が高い。短縮は打ち間違いリスクもある
