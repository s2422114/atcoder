# ABC460 B - Two Rings

- URL: https://atcoder.jp/contests/abc460/tasks/abc460_b
- 結果: AC（考察は自力、型と2乗比較を修正）
- 解法: 2円の円周が共有点を持つ条件は |R1-R2| <= d <= R1+R2
        （離れすぎない かつ 片方が内側に入り込まない。等号は接するケース）
        平方根を避けるため両辺を2乗し、d2 = (X2-X1)^2+(Y2-Y1)^2 で比較
        → (R1-R2)^2 <= d2 <= (R1+R2)^2
- 詰まった点と学び:
  - 【罠1】座標10^9 → 2乗で10^18。int では壊れる。
    変数だけでなく計算結果の代入先(d2)も long long にする（型を全部揃える）
  - 【罠2】sqrt は誤差の元。両辺を2乗して平方根を消す
    → 2乗すると (R1-R2) の符号問題も自動で消える（abs不要）
  - 【罠3】テストケースごとの bool check はループの「中」で初期化
    外に置くと前のケースの結果が残って全部Yesになる
  - ローカルテストは ./main < in.txt でファイルから流し込むと確実
