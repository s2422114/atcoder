# B62 - Path Finding（鉄則本 9章 経路復元）

- 解法: A62 の DFS に「親の記録」を足す
        1. dfs の中、dfs(nex) を呼ぶ直前に par[nex] = pos; で親を記録
        2. dfs(1) 後、cur = N から while (cur != 1) で par をたどり path に積む
        3. ループを抜けた後に path.push_back(1)
        4. reverse して空白区切りで出力
- 学び【単純パス】:
  - 「単純パス」は最短経路ではない。「同じ頂点を2回通らない道」という意味。
    最短である必要はないので、遠回りでもAC
  - よって DP は不要。グラフはサイクルがあると計算順序が決まらないので
    そもそも DP は原則使えない（使えるのは一直線・木・DAG）
  - 最短経路が問われたら DP ではなく BFS（A63）
- 学び【経路復元】:
  - DFS が通った道は visited があるので自動的に単純パスになる
  - 訪問順をそのまま出力するのは誤り。行き止まりで戻った寄り道が混ざる
    例: 辺 1-2,2-3,2-4,4-5 で訪問順は 1 2 3 4 5 だが
        3-4 に辺がないので道になっていない。正解は 1 2 4 5
  - par[] でゴールから逆にたどると、寄り道は経路に現れず自然に消える
- 学び【par を記録する位置】:
  - par[nex] = pos; は dfs(nex) を呼ぶ「前」に置く。
    dfs(nex) に入ると pos が nex に変わり、どこから来たか分からなくなる
  - 「次に進む直前、まだ両方が分かっている場所で記録する」は
    BFS の dist[nex] = dist[pos] + 1 と同じ型
